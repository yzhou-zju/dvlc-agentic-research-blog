Improving heterogeneous robot collaboration: from D-VLC to GPT-guided research

Four robots repair equipment, process spare keys, and deliver them across two floors. Two linked feedback loops connect task execution with software improvement.

Foundation: D-VLC: Decentralized Vision-Language Collaboration for Heterogeneous Embodied Multi-Robot Systems in Unknown Environments.

01 / BACKGROUND

From collaboration to system improvement

A natural-language goal does not say when each robot should search, carry, or operate. An unknown environment also demands shared discoveries, dependency management, and recovery. D-VLC addressed these needs with capability reasoning, compact spatial memory, and asynchronous collaboration.

Longer two-floor tasks exposed waiting, detours, and harmful parallel assignments. We therefore extend the object of improvement to robot software and tests. GPT-6 Astra revises implementation and validation from logs; researchers set goals and acceptance criteria. This feedback structure is inspired by recursive self-improvement (RSI), without changing model weights.

02 / EVOLUTION

Results change the next implementation

Record failures and time → GPT-6 Astra revises code and tests → validate by replay, checkpoint, and full run → retain, narrow, or revert. One predictive-pickup checkpoint fell from 422.1 to 352.1 s; early positioning was later removed after blocking a teammate. Object reference images increased false positives and latency, so were not merged. Evidence and limits.

03 / FRAMEWORK

Task program and coupled feedback loops

At runtime, GPT decomposes tasks, explains failures, and reviews parallel work. A shared coordinator checks dependencies and resources while four robots execute asynchronously. Qwen3.5-4B selects actions and drives exploration. Vision and localization run when the task needs them.

07 / RESEARCH METHOD

GPT-6 Astra as a research agent

The agent inspects logs, edits code, builds tests, and compares results; researchers judge the evidence. A passing local test does not establish full-task speedup. Existing records cannot quantify human time saved.

08 / LIMITS

Evidence boundaries

Recordings establish particular runs; one comparison supports a local conclusion. Simplified Unity grasps do not establish physical hardware ability.
